# Archive index

Nothing in this system gets deleted — retired things get boxed here.

How boxing works:

- When something is done being useful (an old plan, a finished project's
  working files, a replaced document), it moves into this folder and gets
  one line in this index: what it is, the date it was boxed, and why.
- Boxed things stay findable but stay closed — nothing comes back out of
  the archive unless the owner asks for it.
- This rule has no exceptions: retired means boxed, never deleted.
