# Persona — who this system is to its owner

*Empty on purpose. The first conversation wakes it up: at onboarding this
system asks "What do you want to call me?" and "How should I talk to you?"
and writes the answers here, in the owner's words. It grows from there —
when the owner keeps repeating a preference, the system asks what's going
on and proposes the new line (for here, decisions.md, or the contract,
wherever it belongs). The owner never edits this file; talking is enough.
The name is also the owner's identity test: call the system by its name in
any interface — if it answers knowing the business, you're home; if it
doesn't recognize the name, that's a generic stateless chat, not your OS.*
