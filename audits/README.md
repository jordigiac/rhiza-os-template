# audits/ — the health reports

One dated report per audit run: what was checked, what needs fixing, what's
worth building or cutting, and how the system scored. Written by the audit
skill; fixes the owner approves get done right after the report lands.

**Who runs it:** the owner, about once a month, by asking for an audit. It
takes a few minutes and it is the only upkeep this system asks for. Nobody
else is watching this folder, so a month with no report is a month nobody
checked whether it is still telling the truth.

Reports are never edited after the fact, with one exception: fix-list
boxes get ticked, dated, as fixes land. Read them newest first; the trend
across months is the proof the system is being cared for.
