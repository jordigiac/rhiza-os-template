# clients/ — one file per client

*(Working files. The system keeps these current as the owner talks about
their people.)*

Start with a roster in `roster.md` if the list is short, or one file per
client when there's real history to hold. Either is fine; the system asks
before switching.

**What a client file holds:** who they are, what they bought and when, where
they are in the work, what was said in the last session, what they need next,
and anything personal the owner would feel bad forgetting.

**What it never holds:** anything the owner wouldn't want on a screen with
someone else in the room. Health details, money troubles, and anything shared
in confidence stay out unless the owner puts them here on purpose.
