# programs/ — one file per thing you teach

*(Working files. The offer's price and sales link live in
`knowledge/core/offers.md`; the teaching lives here.)*

**What a program file holds:** the curriculum module by module, what each
session covers, the worksheets and materials and where they live, the Zoom
room or platform link, the run dates, and what students keep asking about.

**Why it's split from offers.md:** the offer is what you sell and it has to
stay exact. The curriculum is what you teach and it changes every time you
run it.
