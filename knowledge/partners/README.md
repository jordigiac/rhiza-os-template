# partners/ — the people whose lists you trade with

*(Working files. One file per partner.)*

Joint ventures run on memory: who promoted for you, what they needed, what
converted, and what you still owe them. This folder is that memory.

**What a partner file holds:** their name and business, how big their list
is, what they sell, every promo you've done together (both directions, with
dates and results), what materials they need from you and by when, how they
like to be asked, and the last time you talked.

**Why it matters:** when you're compiling a partner kit, the system reads
these files first. It already knows who gets what and when.
